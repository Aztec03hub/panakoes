- `services/transcriber-batch`: new Python service that runs as the AWS Batch GPU transcription worker on the `panakoes-gpu-transcribe` AMI. Reads Batch-supplied env (`S3_INPUT_URI`, `S3_OUTPUT_PREFIX`, `JOB_ID`, `SESSION_ID`) plus container-static config (`MODEL_PATH`, `SESSIONS_TABLE`, `DEVICE`, `LOG_LEVEL`), downloads the source audio from S3 to a tmpfs scratch dir, loads Whisper-large-v3 fp16 from the AMI-baked weights at `/opt/whisper/models/large-v3.pt`, runs `model.transcribe(..., fp16=True, word_timestamps=True)`, maps the result onto the canonical Panakoes transcript shape (`text`, `language`, `duration_seconds`, `word_count`, `segments[]` each with `words[]`), writes the JSON to `S3_OUTPUT_PREFIX/transcript.json`, and updates the `panakoes-dev-streaming-sessions` DDB row (`status=active` on pickup, then `status=completed` with `transcript_uri` + `duration_seconds` + `word_count` on success, or `status=errored` with a 500-char-truncated `error_message` on failure). Exits 0 on success, 1 on failure so the Batch FailedJobs CloudWatch alarm fires. Module map: `config.py` (pydantic-settings env loader with fail-fast on missing required fields), `s3.py` (URI parser + download/upload helpers), `sessions.py` (one-`UpdateItem`-per-transition DDB helpers with Decimal-safe number coercion), `transcribe.py` (lazy whisper import so unit tests mock the seam without the wheel; tenacity retry on transient `RuntimeError` with exponential backoff capped at 3 attempts; canonical-shape mapper), `main.py` (orchestrator with injection seams for the boto3 clients, model loader, and transcribe fn). Whisper is deliberately NOT a pyproject dependency: the AMI bakes the CUDA-tuned openai-whisper build and pinning it here would duplicate the install or shadow the AMI's build. Multi-stage `Dockerfile` mirrors `services/_template`'s shape (uv-based builder, slim runtime, non-root `app` user) and installs `ffmpeg` for whisper's audio decode. Ships with 30 tests (5 integration via moto S3 + DynamoDB + a stubbed model loader; 25 unit covering config validation, S3 URI parsing + download + upload, DDB status transitions + Decimal coercion + message truncation, transcribe retry behavior + canonical-shape mapping + missing-field handling); coverage gate is 80%, achieved coverage is 90.4%. Closes the runbook-flagged gap from PR #277 where `infra/dev/batch/` referenced ECR repo `panakoes-dev-transcriber-batch` with zero images.
