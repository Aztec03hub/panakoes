- `services/api-index`: root landing page, liveness probe, and friendly 404 for the public API (`api.panakoes.com`). `GET /` is content-negotiated (a polished self-contained HTML page for browsers with a live auth-health badge and route catalog; a JSON index otherwise), `GET /health` returns a fast liveness probe, and any unmatched path returns a friendly 404 that points at the route index. Wired into `infra/dev/api-gateway` as a container-image Lambda behind `GET /`, `GET /health`, and `$default` routes.
