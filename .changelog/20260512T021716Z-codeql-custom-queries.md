- `.github/codeql/`: added 4 Panakoes-specific custom queries layered on top of the existing `security-and-quality` suite (CodeQL is already enabled per task #30). New queries: (1) `panakoes/jwt-env-var-prefix-mismatch` flags Python `os.environ['AUTH_JWT_*']` or TS `process.env.AUTH_JWT_*` reads outside `services/auth/` (validators must use `JWT_*`, signers use `AUTH_JWT_*`, per ADR-039 / ADR-041; this is the PR #218 bug class). (2) `panakoes/iam-policy-resource-star` flags `aws_iam_policy_document` `resources = ["*"]` outside the allowlist (`infra/dev/iam/main.tf`). (3) `panakoes/em-dash-in-source` catches U+2014 / U+2013 characters in committed source that the bash detector misses when files are added via `cat <<EOF` patterns. (4) `panakoes/secret-pattern-in-tf-default` catches AWS access-key / Stripe key / Anthropic key shapes pasted into Terraform `variable` `default = "..."` positions (overlap with gitleaks for drift cases). Native `.ql` queries cover Python; companion bash scanners under `.github/codeql/scripts/` (`scan-iam-star.sh`, `scan-tf-secrets.sh`, `scan-em-dash.sh`, `scan-jwt-prefix.sh`) handle Terraform HCL and cross-language coverage, emitting SARIF 2.1.0 that uploads to the Security tab via `github/codeql-action/upload-sarif@v4`. All four queries ship **report-only** today: `continue-on-error: true` on every scanner step, no required-status-check gating; the existing-findings baseline against `main` surfaces 16 cross-service `AUTH_JWT_SECRET` reads (in `services/ingestion-api/` + `services/session-manager/`, the documented HS256-shared-secret validators awaiting the ADR-041 KMS-signing migration) and 8 `infra/dev/<module>/main.tf` files with `resources = ["*"]` outside the IAM allowlist, all of which need per-statement audit before the queries can be promoted to required checks. Test fixtures (triggering + non-triggering) live under `.github/codeql/test-fixtures/`; `.expected` files next to each `.ql` document expected query rows; `.github/codeql/README.md` documents the local test commands and the procedure for adding a new query. CodeQL pack manifest at `.github/codeql/qlpack.yml` registers the suite; `.github/workflows/codeql.yml` appends the suite to the existing `security-and-quality` invocation via `queries: security-and-quality,+./.github/codeql/queries/panakoes` and adds a parallel `panakoes-scanners` job that runs the bash companions and uploads their SARIF.
