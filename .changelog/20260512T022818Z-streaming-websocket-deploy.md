- `infra/dev/api-gateway-ws/`: new Terraform module that provisions the dev streaming WebSocket API (`panakoes-dev-streaming-ws`, id `a75u8kj039`, `wss://a75u8kj039.execute-api.us-east-1.amazonaws.com/dev`). Separate from `infra/dev/api-gateway/` because a single `aws_apigatewayv2_api` cannot serve both `HTTP` and `WEBSOCKET` protocol types and because splitting state isolates blast radius across the two transport lanes. Routes registered: `$connect`, `$disconnect`, `$default`, `audio-frame`, `transcript-request`; route selection on `$request.body.action`. Stage `dev` with `auto_deploy = true`, default per-route throttling (500 burst / 200 rate), structured-JSON access logging to `/aws/apigatewayv2/panakoes-dev-streaming-ws` (30-day retention, module-local KMS CMK), execution logging at INFO level with `data_trace_enabled = false` so audio payloads never land in CloudWatch. The module also stands up the account-level API Gateway CloudWatch Logs role (account-wide singleton previously unset, hit on first `CreateStage` with `BadRequestException: CloudWatch Logs role ARN must be set`). Smoke-deploy integration target is a 35-line inline Python Lambda (`panakoes-dev-streaming-ws-stub`) that logs every event and forwards to an SQS queue (`panakoes-dev-streaming-ws-frames`, 60s visibility, 4h retention, SQS-managed SSE); the follow-up PR repoints the integration URI from the stub to the real streaming-router Lambda when it lands. Lambda authorizer planned for `$connect` (HS256 JWT via the `panakoes-auth-client` layer, claim shape locked in `services/auth-client/src/panakoes_auth_client/claims.py`) is intentionally deferred to a follow-up PR; `$connect` currently runs with `authorization_type = "NONE"`. End-to-end smoke against the deployed API confirmed all five routes dispatch cleanly (CONNECT → audio-frame → transcript-request → $default → DISCONNECT, status 200 each, integrationLatency under 300ms cold / 60ms warm) with no dangling connections.
- `docs/runbooks/streaming-websocket-smoke.md`: new operational runbook for the streaming WebSocket API. Documents the prerequisites (`websocat`, `panakoes-admin` profile, `jq`), the five-step smoke procedure (purge queue, confirm empty, connect with three test frames, poll queue for the five expected route dispatches, inspect access + Lambda logs), the verification criteria, the Lambda authorizer JWT shape the follow-up PR will validate (HS256, iss `https://auth.panakoes.com`, aud `panakoes-api`, with the full `JwtClaims` field list and the `?access_token=<jwt>` query-string identity-source pattern), rollback posture (revert the bad commit and re-apply, not `terraform destroy`), and three concrete troubleshooting cases (stale deployment, missing Lambda permission, route pointing at a stale integration after a Terraform replace). Added to `docs/runbooks/README.md` index.
