- `scripts/deploy-admin-spa.sh` + `tests/scripts/test_deploy_admin_spa.sh`: repeatable operator helper that builds the admin SPA, uploads `build/` to the S3 origin bucket with per-file `Cache-Control` headers (`public,max-age=31536000,immutable` on hashed assets under `_app/immutable/*`, `no-cache` on `index.html` + everything else, `--delete` to prune stale objects), and creates a CloudFront `/*` invalidation. Replaces the by-hand sequence operators ran after each of PR #225 / #235 / #238 landed. Bucket name and distribution id are discovered at runtime from the `infra/<env>/frontend/` Terraform outputs (`bucket_name`, `distribution_id`, `distribution_domain_name`); no account ids, bucket names, or distribution ids are baked into the script as literals. Flags: `--dry-run` (print every command without executing), `--no-invalidate` (upload but skip the CloudFront invalidation, cheaper for non-content-change deploys), `--skip-build` (re-use an existing `services/admin/build/`), `--env dev|prod` (selects which terraform stack to read outputs from), `--api-base-url URL` (overrides the `VITE_API_BASE_URL` baked into the build; defaults to the dev API Gateway URL). Pre-flight checks: `AWS_PROFILE` is required (exits 2 with an actionable message; named profile must have S3 write + CloudFront invalidation perms), `aws` / `terraform` / `jq` / `pnpm` (unless `--skip-build`) must be on PATH. Exit codes: 0 success, 1 generic build / upload / invalidate failure, 2 bad usage / missing env / missing dependency, 3 terraform state unreadable (wrong account, S3 backend bucket inaccessible, KMS decrypt denied, or module never applied). The script logs via a `printf '%s\n'` helper so messages starting with `--` are never mistaken for printf format flags (same hardening pattern as `scripts/run-auth-migration.sh`). Smoke test suite (7 assertions, all passing) covers `--help` exit 0, `--dry-run` not invoking `aws s3 sync` or `aws cloudfront create-invalidation` (verified via a mock `aws` CLI on PATH that appends to a sentinel file; sentinel must remain empty), missing `AWS_PROFILE` exits 2 with the clear message, unknown flag exits 2, `--env staging` (junk value) exits 2, and `--api-base-url` without a value exits 2. `services/admin/README.md` "Deployment target" section now documents the script with copy-pasteable invocations. `CONTRIBUTING.md` adds an "Operator scripts under `scripts/`" table referencing this and other operator helpers.
