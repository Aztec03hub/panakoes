- `docs/runbooks`: added [`docs/runbooks/admin-dashboard-e2e-smoke-test.md`](docs/runbooks/admin-dashboard-e2e-smoke-test.md), the post-deploy admin-dashboard end-to-end smoke runbook. Covers all four runtime layers (SPA bundle on S3 + CloudFront at `https://dmaopcm3hnxog.cloudfront.net/`, API Gateway HTTP API v2 with the (c+) routing shape from ADR-038 at `https://n2un8ica69.execute-api.us-east-1.amazonaws.com/dev`, the auth + cost-api + admin-api backend services, and the Aurora + DynamoDB data stores). Includes a pre-flight platform checklist (ECS services 1/1, NLB target health, ECR images present, Secrets Manager `LastChangedDate` sanity), layer-by-layer curl steps for `/v1/auth/health`, sign-up, sign-in, and cost-api with the JWT (flagged as known-failing on multi query-param requests today per memory `aws_api_gateway_503_multi_query_params.md`), browser steps for unauthenticated `/dashboard` (validates the bundled static-mock fallback when `VITE_USE_LIVE_HEALTH_AGGREGATOR=false`) and the authenticated `/login` to `/dashboard` to `/cost` flow, a Playwright reference script reading the admin password from `ADMIN_PW` so no secret ever lands in the repo, a curl-only equivalent for CI use today, expected timings (cold + warm baselines with a 5x-slower trigger note per step), a smoke-user cleanup via a one-off run-task that deletes `email LIKE 'smoke-%@test.test'`, and an 11-row failure-mode map keying response codes + log signatures to the specific implicated layer (502 / 503 to integration / NLB, 401 to JWT issuer / audience mismatch, 500 + `permission denied for table "user"` to ADR-039 grant set, etc.). Index entry added in `docs/runbooks/README.md`. Cross-references `auth-db-first-deploy.md` (the one-time cluster bring-up procedure this complements), ADR-038, and ADR-039.
