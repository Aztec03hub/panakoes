Methodology.

How this number was assembled

Per-service spend is computed by tagging every AWS resource at provision time with a panakoes:service tag, then issuing a daily GetCostAndUsage query against Cost Explorer that groups by that tag. Results land in the panakoes-cost-cache DynamoDB table.

The dashboard reads the cache, not Cost Explorer directly. CE charges per request and rate-limits aggressively, which is why the cache exists. The cache_hit field on the response lets the operator see at a glance whether the figure they are looking at came from cache or paid a CE round-trip; both are correct, the provenance just matters when the figure is being defended in a meeting.

Costs are stored as integer cents end-to-end. Floating-point USD has bitten this code path before; the contract is that cents are the source of truth and the dollar string is a presentation-layer concern, formatted at the very last step.
