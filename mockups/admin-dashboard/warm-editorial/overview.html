Aggregator notes · pre-release

The health-aggregator service does not yet exist. This dashboard reads from a static static/dashboard/health.json fixture so the operator console can be developed and tested ahead of the live probe pipeline. Slice 4 of the implementation backlog will replace the fixture with a proper aggregator backed by ECS service-discovery and CloudWatch synthetic checks.

When the aggregator ships, the same JSON shape is preserved. The page contract is the HealthSnapshot type defined in services/admin/src/lib/types.ts; the only thing that changes is which side of the network boundary populates it.
