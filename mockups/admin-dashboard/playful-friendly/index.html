About this mockup

This is one of five design directions for the Panakoes admin dashboard. The others live on sibling branches. The intent of playful / friendly is a dashboard that's enjoyable to spend time in even when nothing is wrong: warm off-white paper, muted purple primary, soft shadows, conversational empty states, the destructive ops still feel weighty.
