A quiet console for an all-hearing platform.

Variant one of five admin-dashboard mockups for Panakoes. This direction is the Swiss school: a single sans family, monochrome with one restrained navy accent, twelve-column grid, generous whitespace, tabular figures wherever a number can appear. The product is competent. The interface does not need to shout about it.

Design language The four rules that make this variant feel like itself.

Restraint over decoration
Typography
1family
Inter Tight in five weights. Hierarchy via weight + size, never colour. Numbers in tabular figures everywhere.
Palette
9+1 accent
Cool-neutral grayscale ramp. Deep navy reserved for primary action and active state. Status hues low-chroma, operational-only.
Grid
12cols
1280px max content width. 24px column gap, 48px page gutter, every element on the grid.
Forbidden
0shadows
No drop-shadows, no rounded blobs, no gradients, no illustrations. Borders and rules carry the weight.
