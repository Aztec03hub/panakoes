READ FIRST. Tier 3 operations write to the audit log before and after they run (ADR-032). The typed-confirmation gate is enforced by admin-api regardless of what the UI does.

design direction notes // what makes this variant different

  TYPOGRAPHY .... JetBrains Mono only. regular + bold. no italics for emphasis.
                  emphasis is ALL CAPS or [bracketed].
  COLOR ......... pure #000 on pure #fff. one accent (#d97706 amber) reserved
                  exclusively for destructive ops + WARN status. no greens.
                  status is text labels: [OK] [FAIL] [WARN] [UNKNOWN].
  LAYOUT ........ full-bleed tables. 1px hard borders everywhere. zero rounded
                  corners. zero shadows. zero gradients. terminal-prompt inputs.
                  ASCII separators (>>, // , #) instead of icons.
  PERSONALITY ... refuses to perform polish. trust through transparency.
                  built for operators who don't need a UI to babysit them.
