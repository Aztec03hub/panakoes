# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) verbatim.

The full text lives at the canonical URL above. By participating in this project (as a contributor, maintainer, or community member) you agree to those terms.

## Enforcement

Concerns about a participant's behavior should be reported privately to:

`conduct@lafayettelabs.com`

All reports are reviewed and investigated. Maintainers will respect the reporter's confidentiality. Outcomes range from a private clarification to removal from the project, depending on severity and context, following the Enforcement Guidelines in the Covenant.

## Scope

This Code applies in all project spaces (issues, pull requests, discussions, code review, the project website) and when an individual is officially representing the project in public.
